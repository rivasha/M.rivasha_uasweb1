📚 Selamat Datang di Perpustakaan Digital

Aplikasi Perpustakaan Digital merupakan sistem berbasis web yang digunakan untuk membantu admin dalam mengelola transaksi peminjaman dan pengembalian buku secara efektif dan terstruktur.

📝 Cara Menggunakan Aplikasi

  1. Login sebagai admin
  2. Masuk ke menu Transaksi
  3. Input data peminjaman atau pengembalian buku
  4. Simpan dan lihat daftar transaksi
