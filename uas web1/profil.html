Tentang Perpustakaan

Perpustakaan Digital Kampus merupakan aplikasi berbasis web yang dirancang untuk membantu pengelolaan data perpustakaan secara terkomputerisasi. Aplikasi ini digunakan oleh admin untuk mengelola transaksi peminjaman dan pengembalian buku.

Tujuan

  • Meningkatkan efisiensi pengelolaan data perpustakaan
  • Mengurangi kesalahan pencatatan manual
  • Menyediakan sistem informasi perpustakaan yang mudah digunakan

Fitur Aplikasi

  1. Login Admin
  2. Input Transaksi Peminjaman Buku
  3. Daftar Transaksi Perpustakaan
  4. Manajemen Data Perpustakaan
